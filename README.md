# SimGuard AI – MVP

Simulation-based crowd & emergency safety system built for Simverse Hackathon 2025.

## Problem
Crowded campuses and public venues lack predictive systems to simulate emergencies and crowd behavior before incidents occur.

## Solution
SimGuard AI uses agent-based simulation to model human movement, detect congestion, and suggest safer evacuation strategies.

## Features
- Crowd simulation using agent-based logic
- Emergency trigger (fire / exit blockage)
- Crowd density heatmap
- Evacuation route suggestion

## Tech Stack
- Python
- Streamlit
- Basic agent-based simulation

## How to Run
1. Clone the repository  
2. Install dependencies  
   `pip install -r requirements.txt`
3. Run the app  
   `streamlit run app.py`
